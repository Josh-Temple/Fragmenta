# 18パターンの選択ガイド：統合候補（2026-11-14）

過去の [Draft PR #42](https://github.com/Josh-Temple/Fragmenta/pull/42) のうち、18例それぞれの「向かない場面」「最初に確認すること」「理由付きの関連例」を、同PRのHEAD `38c816d2f8ceca0998ef2eb8b575991138d52129` から採用した。同PRは古い親候補を前提としているため、ブランチ全体をマージせず、現行の `patternGuides`、生成例および18 IDを確認し、必要なデータと画面への接続を取り込んだ。関連例は使い分けや併用を考えるための候補であり、すべてが同じ機能の代替品という意味ではない。

## 現在の実装への接続

- 個別の詳細画面と、18項目を開閉できる共通ガイドに同じ説明を表示。既存の導入手順、確認事項、制約、権利表示は維持した。
- 英文のガイド領域に `lang="en"` を付けた。関連リンクの見出しIDはパターンごとに一意とし、リンクは各詳細画面の実際のルートへ遷移する。
- 別のパターンへ移動した際、タイトルにフォーカスを移す。既存のスクロール位置とパラメータ初期化の処理を維持する。
- 18件の定義とガイドのID集合、各2件の重複しない参照先、自己参照の禁止と説明の存在をビルド時に検査。Chromium用検査では、各詳細画面のリンク表示と1件のEnter操作・移動後の見出しフォーカスを確認する。
- 最初の統合HEAD `6fda5a6a48e85c6c3355bebbf0935a12bca134cc` では、18件の新しいリンク検査とEnter操作は通過したが、共通ガイドの既存検査が同じ遷移先を持つ別の関連リンクを先に取得して停止した。リンクのある開閉項目を明示して対象を絞り、修正後のHEADで再検証する。

## 限界

この説明は現行のサンプルを選ぶための草稿であり、独立した内容レビュー、翻訳、実Android・支援技術による確認は未実施。画面の見た目や使い勝手を自動検査だけで保証しない。サンプルのコピーや関連リンクは利用許諾を与えず、既存のパターンごとの権利確認状況も変更しない。元のDraft PR #42は参照可能なまま保持する。

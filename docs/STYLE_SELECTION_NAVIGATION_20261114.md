# スタイル選択とURLの整合（2026-11-14）

従来はURLの `style` を初回表示やURL変更時には読み取る一方、一覧やスタイルAの選択で内部状態だけを変更していた。そのため、変更後のURLを共有・再読み込みすると以前のスタイルが開き、同じURLへの再遷移でも画面とURLが一致しない場合があった。

この候補ではURLの `style` を選択状態の基準にし、一覧と選択欄からの変更をURLへ反映する。`style` 以外のクエリは保持する。URLが無指定または未登録の場合は従来どおりSwissを表示し、ブラウザの戻る操作でも表示をURLに追従させる。

また、比較対象が「比較しない」またはスタイルAと同じになった場合は、2スタイルの配合を解除する。後から有効な比較対象を選んでも配合を勝手に再開しない。選択変更時は以前のコピー結果表示も消す。CSS出力の意味や、2スタイルの配合指示の内容は変更していない。

自動検査は選択欄と一覧からの変更、直接URL、再読み込み、ブラウザの戻る、他のクエリの保持、配合の解除と再開防止を対象とする。人間による受入、実Android・支援技術による検証は別途必要。

# 主内容の領域の重複を修正（2026-11-14）

共通レイアウトは各ページの内容を `main` 要素で囲んでいる。一方、パターン詳細、コレクション一覧・詳細、ライセンスの各ページでも内側に `main` を置いていたため、同じ画面に主内容の領域が入れ子になっていた。

内側の要素を表示用の `div` に変更し、共通レイアウトの `main` を各画面で一つだけ残した。既存のクラス、見出し、ナビゲーション、文章や権利表示は維持した。コレクションの未検出画面も同じ修正の対象に含む。

ブラウザ検査では実際に表示した各ルートについて `main` と `role="main"` の合計が一つであることを確認する。正常な画面だけでなく、存在しないパターン・コレクションの表示も対象にする。この検査は支援技術での読み上げや全般的なアクセシビリティの受入を代替しない。

画面遷移時の位置も見直し、パターン詳細、コレクション一覧・詳細、ライセンス画面では、先頭へ戻ってから見出しにフォーカスを移す。パターンやコレクションが存在しない場合も対象に含める。Chromiumではそれぞれの遷移先で実際に見出しがフォーカスされることを確認する。

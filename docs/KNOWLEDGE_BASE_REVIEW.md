## 今回の候補

**ローカル作業のみ。PR作成、マージ、Preview・Productionデプロイは保留。** GitHubへのpushが自動デプロイを起こさないことは確認できていないため、pushしない。

- `data/content-ideas.json`が唯一の編集正本。15分野180件、すべて`proposal`。
- 未レビューの参考メモは68件。元の57件を保持し、そのうち27件を補強。新規11件を追加。合計38件に使用例・実装上の注意・アクセシビリティ・AI指示例を追加した。
- 29件に計13種類の参考資料を紐付けた。資料の一部を確認したもので、各メモ全体の事実確認や利用許諾の完了を意味しない。未レビュー・根拠未確認の状態は維持している。
- 相互関連154組（308方向）は保持。うち17組に種類と理由を付記し、その他は関連理由を未確認と表示。既存のスタイル・パターンへの20参照を保持した。
- 英語名は38件、別名は一部のみ。残りの翻訳、分類、関連理由は未整備。
- スキーマ2は既存の`relatedIdeaIds`と互換性を保ち、`relations`、`sourceCatalog`、任意の追加説明を導入。`scripts/knowledge-baseline.json`で基準時のID、カテゴリ、57件の文章、154組を保護する。文章を意図的に改訂する場合は変更内容をレビューし、基準ファイルの更新も明示的に行う。
- `catalog:export`でJSON、Markdown、`llms.txt`と本リポジトリの索引を同じ正本から生成する。静的ファイルの存在はAIサービスによる自動取得を保証しない。

## 実装した主な内容

- 検索・分野・参考メモの有無をURLに保存し、戻る・再読み込みに対応。検索結果から詳細を開いた場合、一覧へのリンクに検索条件を引き継ぐ。
- 24件ずつ表示し、180件まで追加表示できる。空結果と不明IDの案内、詳細ページ間の移動、関連理由、参考資料の表示を整備。
- 全体検索に知識ベースの企画を公開コンテンツとは別枠で表示。既存パターンとスタイル図鑑から関連企画に戻れるようにした。
- 詳細ページを連続して移動すると以前のスクロール位置が残る不具合を修正。
- 主要ページを遅延読み込みし、初期JavaScriptへの負担を抑えた。`terminal.local`をVite開発サーバーの許可ホストに追加した。これは開発プレビュー用の設定。

## 確認結果

- Node.js 22.23.4：`npm ci`、`catalog:verify`、`catalog:export`、`catalog:smoke`、`catalog:regression`、`typecheck`、`lint`、`build`は成功。ビルドの`design:verify`と`tools:verify`も成功。
- 元のブランチでは`catalog:smoke`が存在しない変数名を探して失敗し、`build`も停止した。検査対象を修正した。
- 回帰テストは、既存下書きの削除・上書き、既存の相互リンクの削除、存在しない出典IDを拒否することを一時データで確認した。
- Cloud Browserの通常幅で、英語検索、分野と下書きの複合絞り込み、URL・再読み込み・戻る、0件、不明ID、関連項目の移動、180件への段階表示、スタイルの選択と記事表示、既存パターンからの戻りリンクを確認した。JSONの180件・スキーマ2と`llms.txt`の表示を確認。実測した性能値ではない。
- コピーはローカル画面で失敗し、画面に失敗メッセージが出た。表示文とクリップボードの一致は確認できていない。原因は未確定。MarkdownリンクはCloud Browserが`ERR_BLOCKED_BY_CLIENT`を返し、ブラウザで開けなかった。生成ファイルの内容はローカル検査で確認した。
- 360px・390px・タブレット幅、実際の200%ズーム、Android実機、音声読み上げ、reduced motion、ライト・ダーク双方、正式な性能測定と全リンクの実ブラウザ巡回は未実施。通常幅の確認をこれらの代替にしない。
- この作業の制作担当による別工程の点検と自動検査は行ったが、別人・別エージェントによる独立レビューは実施できていない。
